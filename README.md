# novo-website

The Novovine website (novovineinc.com), hosted on Cloudflare Pages.

- `index.html` — the whole site: page, styles and the 202-ingredient catalog.
- `assets/` — the Novovine logo (green for light backgrounds, cream for green).
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` — browser and home-screen icons.

Every push to `main` goes live automatically.
To add or remove an ingredient, edit the `CATALOG` lists near the bottom of `index.html`.
